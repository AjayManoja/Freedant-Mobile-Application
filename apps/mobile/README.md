# Mobile app

Expo (React Native) app for Android, with a web export for demos.

- **Stack:** Expo Router, TypeScript (strict), NativeWind, TanStack Query, Zustand, react-hook-form + zod, FlashList, expo-secure-store, i18next
- **Design source:** [`design/`](../../design/README.md)
- **Scaffolded in:** Phase 2 (Foundation); screens built during the Phase 3 sprints
